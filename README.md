# Scoop bucket

Scoop manifests for [MiFaZhan](https://github.com/MiFaZhan)'s tools.

```powershell
scoop bucket add mifazhan https://github.com/MiFaZhan/scoop-bucket
scoop install mifazhan/jms-client
```

## Available

| App | Description |
|---|---|
| `jms-client` | JumpServer v4 bastion CLI and MCP server |

Manifests here are generated and committed by [GoReleaser](https://goreleaser.com)
from each tagged release; edit them upstream, not in this repository.
